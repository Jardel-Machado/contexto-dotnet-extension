# Create Context (.NET)

Crie automaticamente a estrutura completa de um novo contexto em projetos .NET com apenas um clique.  
Ideal para arquiteturas em camadas que utilizam as divisões clássicas: Dominio, Aplicacao, Infra, API, DataTransfer e Testes.

## Recursos

- Criação automática de arquivos e pastas por contexto.
- Integração com PowerShell.
- Suporte a AutoMapper ou Mapster.

## Como usar

Clique com o botão direito em qualquer lugar da árvore de arquivos no VSCode  
➡️ Selecione: **"Criar Novo Contexto .NET"**
